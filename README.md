# 定位水印相机（iOS MVP）

原生 SwiftUI + AVFoundation + CoreLocation + Core Graphics + Photos 实现，最低支持 iOS 16，无第三方依赖。

## 运行

1. 用 Xcode 打开 `GeoWatermarkCamera.xcodeproj`。
2. 在 Target 的 Signing & Capabilities 中选择自己的 Team；Bundle Identifier 如有冲突可自行修改。
3. 连接真机并运行。相机、真实定位和相册写入建议全部在真机验证。
4. 首次启动依次允许相机和定位；首次保存照片时允许添加到相册。

模拟器没有真实相机，工程可编译，但完整拍摄链路必须使用 iPhone 测试。

## 已实现

- 自定义相机界面、前后摄像头、闪光灯和 1×–5× 变焦
- 秒级更新时间水印，十进制度/DMS 坐标，可编辑地址和自定义文字
- 简约黑底、白色卡片两套模板
- 水印任意拖动、三分线/中心线/边缘吸附、双指缩放
- 竖屏与左右横屏自动切换，相机预览、成片方向和水印同步旋转
- 水印背景透明度可调并自动持久化
- 相机画面文字本地识别：支持关闭、识别后提示、自动加入三种模式，并对稳定结果去重
- 水印位置与大小自动持久化
- 原始照片像素级烧录水印并另存到系统相册
- aspect-fill 预览裁切与原图像素坐标换算，前摄预览/成片镜像一致
- 保留原照片元数据并补写 GPS EXIF
- 相机、定位、相册权限拒绝后的明确降级与提示
- 文字识别通过 Apple Vision 在设备端完成，不上传相机画面

详细分层和数据流见 [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md)。

## 已知的 MVP 限制

- 仅支持照片模式；视频水印安排在第二阶段。
- 不同 iPhone 摄像头的“超取景框”行为可能有细微差异，发布前应覆盖目标设备做边缘位置回归测试。
