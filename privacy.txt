1. 基础拍摄与权限
本应用无需注册本应用账户。相机用于照片、视频、工作记录与语言学习取图；麦克风仅用于视频环境声音，拒绝后可静音录像。系统照片选择器只导入您选择的图片；读取最近照片需要相册权限。拍照、工作记录、语言学习分别设置保存原片、水印成片、记录卡或学习卡，也可关闭自动保存到相册。工作记录草稿和主动收藏的学习卡存于本机记录库，不要求相册权限。视频另按视频流程处理。系统相册照片可能依您的 iCloud 设置同步；删除应用不会删除相册中的照片。

2. 本机处理
滤镜、美颜、水印排版、二维码安全检查、主体抠图、裁剪与图像缩放在本机完成；自动文字 OCR 已停用。本机不分类物品，不提供系统朗读。已开启的位置水印、保存照片位置或工作记录拍摄定位需要时请求位置；不使用自动地址时不进行地址解析，后台停止定位。地址解析使用系统 CLGeocoder，可能联网。保存照片位置默认关闭，此时清除导出原片与成片的来源 EXIF/IPTC/XMP（含 GPS），保留像素与方向；打开后允许保留来源元数据或写入坐标。关闭 GPS 不删除可见的位置文字或本机记录中的拍摄位置。首版天气暂时停用。

本机工作记录保存现场原片、预览图、拍摄时水印、定位时间与精度、事件和备注。可使用记录的拍摄坐标补解析地点，也可手动修正显示地址；修正不会改变原始拍摄坐标。新版本不再提供人物栏，历史记录可能保留旧版本填写的人物信息。学习收藏保存学习卡及用户选择保留的配图。这些文件可能随设备备份保存；删除应用会移除应用文件，钥匙串可能保留。记录删除先移入本机回收区，可撤销最近删除，相册导出照片需在系统相册单独删除。

卫星定位图默认关闭。主动开启时，Apple MapKit 根据记录的拍摄坐标请求地图图块与卫星影像；位置不随当前手机位置改变。生成快照保存在该记录，地图不会发送给 AI。网络失败不影响记录保存，可重试或选择不含地图导出。卫星图并非拍摄时刻的实时影像。开启地图或显示坐标的导出卡片会公开可见地点，即使关闭照片 GPS 元数据也是如此。地图服务的数据处理参见 Apple 隐私说明：https://www.apple.com/legal/privacy/data/en/apple-maps/

3. 可选云端 AI
云端授权默认关闭，预选接入口、保存密钥或同意服务商账户协议不等于允许本应用上传。需要在 AI 设置查看实际接收接口、经营主体、联系方式、隐私及 API 数据条款，确认已启用的看图识别与现场事件、文字学习、发音、卡通图片编辑用途，点击“同意并测试”一次授权。未授权用途不能调用；相同接收方与用途内切换普通模型或音色无需重复同意。更换接口或地域、增加上传用途、接收方说明或实质隐私条款变化时，仅对变化范围重新确认，保留配置、密钥和照片。识物、事件生成、语言学习与发音仅使用云端，未授权、未配置、离线或失败时明确提示，不切换本机识物、系统朗读或其他收费平台。
云端 AI 由您自行选择并使用自己的服务账户调用。经您明确授权后，所需图片或文本由设备通过 HTTPS 直接发送至所选接口，不经本应用运营者的服务器转发或留存。服务商及中转经营者对其实际数据处理行为依法承担相应责任，具体安排以适用的 API 服务条款为准；本应用仍依法承担客户端处理、安全、告知、授权、最小化发送和撤回等自身义务。用户自行配置不免除运营者的法定义务，也不意味着服务商已经同意本应用全部使用场景。
语言学习看图和工作记录的“AI 写事件”发送重编码且去 EXIF/GPS 的照片，最长边 1024 像素、最大 256 KiB；语言学习按点击目标裁剪。工作记录不会自动生成事件，不额外附加手写人物、位置或水印元数据。AI 事件润色仅发送当前事件文字。学习内容发送名称、类别、语言组合和学习深度；发音发送词汇或句子、语言、模型与音色，不上传用户录音。可选卡通化在用户主动点击确认后发送去元数据的主体照片和编辑提示词，原照片保留。图片和音频从供应商指定的结果存储地址下载，不附模型密钥。接口检查仅在点击后发送合成图片或固定测试词，图片编辑检查会实际生成合成配图。调用可能计费。
二维码先在本机检查，发现时不上传相关图，也不读取载荷或自动打开链接；可能受画质影响，不保证绝对检出。删除 EXIF/GPS 不是匿名化，照片像素可能包含人脸、住处或其他私人信息。请勿上传不必要的证件、医疗资料或未经同意的他人照片。

4. 接口与密钥
接入口包括百炼、火山方舟、智谱、Kimi、硅基流动及用户自配兼容服务。实际接收接口及所选用途在 AI 设置中显示；依据真实 API 域名显示参考信息，不因连接名或模型品牌推定接收方。官方 API 条款参考可从 AI 设置、法律信息页及本公开页面查阅；不是本应用对服务商、账户或上游的合规认证。域名和 HTTPS 不证明数据只在境内处理或不用于训练。
API 服务商及其上游可能接收 IP、请求时间、账户鉴权、提示词、模型/音色与所需图片或文本。发音服务返回签名音频时，还会向其指定的音频存储域名下载，不附模型密钥。账户隐私政策、API 业务数据协议、具体模型、地域和套餐可能不同；不能将聊天 App、官网账户或其他套餐的条款直接套用。具体留存期限、训练用途、上游、处理地域和删除流程按适用约定核实，本应用不统一承诺零留存、不训练、境内处理或绝对安全。
自定义中转保留，但授权前须填写实际经营主体、联系方式、隐私及 API 服务条款的 HTTPS 地址、上游或不转发说明。信息由用户提供，未由本应用独立核实，填写完整不等于获得合规认证；未知经营者或上游时不要上传。接收方说明变化后旧授权不可用于新的调用。
各服务的年龄、输入内容和账户使用限制不同。本人及使用场景须符合适用要求；例如硅基流动服务仅面向成年人，且条款禁止上传未成年人的个人信息，不能以监护人同意绕过供应商限制。本应用的授权确认不是年龄验证，不替代依法必要的监护人同意、敏感信息单独同意、跨境手续或服务商许可。
密钥保存在本机设备限定钥匙串，不回填 UI，不写入应用偏好；只发送到所配置 API，下载签名音频不附模型密钥。自定义中转会收到密钥，勿填写不属于该服务的密钥。偏好、手动地址、自定义文字与品牌设置存于本机，可能随系统备份保存。
兼容地址拒绝数字 IP 与常见本地域名，但没有证明所有 DNS 解析或代理路线都在公网；服务运营者与上游仍须核实，勿将此校验视为安全认证。

AI 来源说明
基础云端名称卡、详细学习卡及应用后的 AI 文案显示来源提醒；相应 JPEG 还写入补充性 AI 生成描述、应用/运营者和生成编号。编号不是上游请求编号，不包含密钥。手动修改已应用 AI 文案仍保留提醒，清空文字后重置。旧版已保存照片或已丢失来源的文字不能自动追溯。该补充信息不代表已满足所有地区的 AI 标识标准，正式发行前仍须复核；AI 内容可能错误，发布时应遵守适用要求。

5. 取消、撤回与权利
AI 设置中关闭云端授权会清空已批准用途与接收方记录，停止后续发送并取消客户端未完成任务；也可关闭暂不使用的发音或卡通照片功能。已送达的数据不能因此从服务商系统撤回。您可清除本应用全部 AI 密钥并撤回授权；钥匙串未必随卸载删除。相册照片由您在系统相册删除，临时文件尝试在完成或失败后清理，异常退出可能残留。
